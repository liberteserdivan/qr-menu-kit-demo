QR Menu Kit — User Guide

Your menu becomes a fast mobile website. Guests scan a QR code on the table and see it on their phone. You need no server, no monthly fee and no coding.

What you need: a computer with Chrome, Edge, Firefox or Safari. Internet is needed only for publishing.

Privacy: the editor runs only on your computer. It sends nothing anywhere, and the menu site has no tracking and no cookies.

1. Setup (2 minutes)

  1. Unzip QR-Menu-Kit.zip into a folder, for example Documents/QR Menu Kit.
  2. Double-click editor.html. It opens in your browser and works offline.
  3. Choose your language (English / Türkçe) at the top.
  4. The sample menu is loaded so you can see how everything works. When you are ready, click New blank to start your own menu, or edit the sample.
Your work is autosaved in this browser. Use Save project now and then to keep a backup file (.qrmenu.json). That file is also how you move your menu to another computer.

2. Business details and logo

Open the Business tab.

  • Business name, Tagline, Highlight badge (e.g. "Open daily 8–22").
  • Upload logo: PNG with a transparent background works best (SVG and JPG also work). The editor shrinks large files automatically.
  • Currency symbol (₺, $, €…) and whether it goes before or after the price.
  • Opening hours, address, phone, Instagram, Wi-Fi password and footer text. An empty field is simply hidden.
  • Menu labels: the text of the search box, the "Sold out" label and "No results". Translate these if your menu is in another language.

3. Colours and style

In the Design tab, click a preset or set your own Background, Text, Accent and Card colours, then choose a Font style and Corner roundness. The preview updates instantly.

Tip: keep strong contrast between text and background so the menu is easy to read in a dim restaurant.

4. Adding categories and items

In the Menu tab:

  1. + Add category creates a section (e.g. Breakfast, Coffee, Desserts).
  2. + Add item adds a product to that category. Fill in Item name, Price and Description.
  3. Tags: words separated by commas, e.g. Vegan, Spicy, New.
  4. Photo: click the square on the left and choose an image. Photos are resized to 900 px for fast loading.
  5. ↑ ↓ move items and categories. Moving an item past the top or bottom of its category moves it into the next category.
  6. Duplicate copies an item (handy for sizes and variants). Delete removes it after you confirm.

5. Changing prices

Type the new price in the item's Price field. You can also type 45 / 60 for two sizes.

To mark something as unavailable for today, untick Available. The item stays on the menu, greyed out with a Sold out label.

Then Export ZIP again and upload it again (step 7). Your QR code does not change, because the address stays the same.

6. Making the QR code

  1. Publish your menu first (step 7) so you know its web address, e.g. https://greenfork.netlify.app/.
  2. Open the QR code tab and paste the address. The address should start with https://.
  3. Optionally change the QR colour. Keep it dark on a light background or some phones cannot scan it.
  4. Download PNG (for print, 1200 px) or Download SVG (sharp at any size, for print shops).
  5. Print table cards opens a page with 4 cards on A4 and your logo, name and a short line of text. Choose "Print" or "Save as PDF".

Always test-scan with two different phones before printing many copies.

7. Publishing (free)

Click Export ZIP (or Export to a folder in Chrome or Edge). Unzip it. The folder contains:

FileWhat it is
index.htmlthe menu website
menu-data.jsyour menu (do not edit by hand)
assets/logo and photos
project.qrmenu.jsonyour editable project (reopen it in the editor later)
menu-qr.png / .svgthe QR code, if you entered an address

Double-click index.html to check it. Then choose one host:

Option A: Netlify Drop (easiest)

  1. Go to app.netlify.com/drop.
  2. Drag the unzipped folder onto the page.
  3. Create a free account so the site is kept (drops without an account are temporary). In Site settings you can rename the site, which gives you yourname.netlify.app.
  4. Update later: open your site → Deploys, then drag the new folder onto it.

Option B: GitHub Pages

  1. Create a free GitHub account and a new public repository, e.g. menu.
  2. Add file → Upload files and drag in the contents of the folder (so index.html is at the top). Commit.
  3. Settings → Pages → Build and deployment: Source "Deploy from a branch", branch main, folder / (root), then Save.
  4. After about a minute your menu is at https://USERNAME.github.io/menu/.
  5. Update later: upload the new files again. They overwrite the old ones.

Option C: Cloudflare Pages

  1. Create a free Cloudflare account and go to Workers & Pages → Create → Pages → Upload assets.
  2. Name the project and upload the folder. Your menu is at https://PROJECT.pages.dev.
  3. Update later: create a new deployment with the new folder.

Option D: Your own domain or hosting

Upload the folder's contents with your host's File Manager or FTP, e.g. into public_html/menu/. Your menu is then at https://yourdomain.com/menu/. Netlify, GitHub Pages and Cloudflare Pages also let you connect a custom domain for free in their settings.

Hosting interfaces change from time to time. If a button has moved, search the host's help pages for "upload static site" or "drag and drop deploy".

Updating your menu later: repeat these 4 steps every time

  1. Open editor.html. Your menu is still there. If it is not, use Open project and pick your .qrmenu.json file.
  2. Make your changes: prices, items, photos, sold out.
  3. Click Export ZIP and unzip it.
  4. Upload the new folder to the same place as before, replacing the old files:
    • Netlify: Site → Deploys → drag the folder
    • GitHub Pages: Add file → Upload files → commit
    • Cloudflare Pages: Create deployment → upload the folder
    • Your own hosting: overwrite the files via File Manager or FTP

Do NOT make a new QR code or reprint it, and do not change the site name or address. The QR stays valid. Check the change on your phone (pull down to refresh). Keep the newest .qrmenu.json as your backup.

8. Troubleshooting

ProblemFix
The site is blank or says "menu-data.js not found"index.html and menu-data.js must be in the same folder. Upload the contents of the unzipped folder, not the ZIP file itself.
GitHub Pages shows 404Wait 1–2 minutes. Check that index.html is at the top of the repository (not inside a subfolder) and that Pages is set to main / root.

Old prices still showYour phone shows a saved copy. Pull down to refresh, or wait a few minutes after uploading.

"Browser storage is full"Use smaller photos and Save project regularly.

9. FAQ

Is there a monthly fee? No. The kit is a one-time purchase. Netlify, GitHub Pages and Cloudflare Pages have free plans that suit a menu site. Their plan terms are set by those companies and can change.

Do I need internet to edit? No. The editor works offline. You only need internet to upload.

Can I make menus for several businesses? Yes, one project file per business. See LICENSE.txt for what the licence allows.

Can I have two languages? Make two projects (e.g. Turkish and English), publish both and link them, or print two QR codes.

Does it collect guest data? No. It has no forms, no cookies and no analytics. If you want visit statistics, your host may offer them.

Can guests order or pay? No. This is a view-only digital menu, by design: no servers and no fees.

Do I have to re-print the QR when prices change? No. The QR points to your web address, so just re-upload the new export to the same place.

Can I edit the HTML or CSS? Yes, the files are plain HTML. Note that the editor overwrites index.html on the next export.

Which browsers work? Current Chrome, Edge, Firefox and Safari. Guests can use any modern phone browser.

Where is my data stored? In your browser's local storage on this computer, and in the project files you save. Nowhere else.
